# Двусторонняя интеграция с ChatGPT (серверная часть)

Эта версия предоставляет защищённые REST endpoints. **Это не готовое подключение к конкретному чату ChatGPT.** Чтобы ChatGPT мог вызывать их, требуется отдельно настроенный совместимый инструмент/коннектор, поддерживающий Bearer-аутентификацию. Не публикуйте ключ в переписках или в GitHub.

## Настройка Railway

Создайте новую секретную переменную `INTEGRATION_TOKEN` со случайным значением длиной не менее 32 символов. Используйте отдельный секрет, отличный от `TELEGRAM_BOT_TOKEN` и `TELEGRAM_WEBHOOK_SECRET`. Не коммитьте секреты в репозиторий.

При отсутствии корректного `INTEGRATION_TOKEN` endpoints отключены (HTTP 503). При неверном ключе возвращается HTTP 401. Все запросы требуют заголовка `Authorization: Bearer <INTEGRATION_TOKEN>`.

## Маршруты

- `GET /integration/chats` — список архивированных чатов
- `GET /integration/messages/{chat_id}?limit=50&before_id=...` — сообщения и пагинация
- `GET /integration/report/{chat_id}` — готовый анализ
- `GET /integration/notes?limit=30` — заметки для обоих ассистентов
- `POST /integration/notes` — сохранение заметки в JSON, например `{"subject":"Мирослав","content":"Подтверждённый вывод, который нужно сохранить"}`

Telegram-команда `/notes` показывает последние 10 общих заметок. Запись заметки происходит только через авторизованный POST. **Бот пока не использует заметки автоматически в своих ответах.**

## Безопасность и ограничения

- HTTPS обязателен.
- Bearer token даёт доступ ко всем сохранённым чатам и заметкам; храните его только в секретах доверенного коннектора.
- Это REST API, а не MCP server и не автоматически установленный ChatGPT connector.
- История данного чата ChatGPT не передаётся автоматически. Для сохранения вывода нужен явный вызов POST через подключённый инструмент.
- Удаление заметок, разграничение доступа по контактам и журнал доступа ещё не реализованы.
- Перед подключением стороннего клиента рекомендуется сделать репозиторий приватным, отозвать ранее показанный Telegram-токен и проверить Railway deploy.
