# Прямой обмен Alexey AI ↔ ChatGPT через защищённый браузер

Прямой доступ к архиву реализован как личный веб-портал на Railway:

**https://alexey-telegram-ai-production.up.railway.app/bridge**

Здесь ChatGPT может читать доступные сообщения и создавать общие заметки через подключённый авторизованный браузер по явному запросу пользователя. Это **не** доступ к системной памяти ChatGPT; сведения из бесед ChatGPT попадают в Telegram только если пользователь отдельно просит сохранить заметку. Автоматической выгрузки всей переписки в память ChatGPT нет.

## Подключить один раз

1. В личном диалоге с **@aialexey11_bot** отправь **/sync_link**.
2. Бот выдаст одноразовый длинный код (действует 10 минут) и ссылку на портал.
3. Открой ссылку в **предложенной ChatGPT настройке браузерного профиля**, введи код только на сайте Railway и сохрани состояние браузера. Никогда не присылай код самому ChatGPT.
4. Когда профиль готов, можно спрашивать ChatGPT: «Посмотри в моём Telegram-архиве через подключённый браузер, что обсуждали с ... вчера», «Найди сообщение о ...», «Добавь общую заметку о ...».
5. Для чтения новых сообщений ChatGPT каждый раз обращается к серверу через подключённый браузер - не по автоматической синхронизации памяти.

Если вход завершился ошибкой, сгенерируй новый код командой **/sync_link**. Код одноразовый; на каждый новый браузер потребуется новый. Сеанс хранится до 30 дней. Для выхода есть кнопка «Выйти»; старый сеанс отзывается сервером.

## Возможности браузерного портала

- **/bridge/chats** - список чатов, поиск по имени, переход в переписку.
- **/bridge/chat/CHAT_ID** - текст переписки и история, в том числе отметки удалений/изменений.
- **/bridge/search?q=...** - поиск по текстам и названиям чатов.
- **/bridge/notes** - общие заметки. ChatGPT может добавить заметку через форму; бот покажет её по /sync_notes.
- **/bridge/status** - состояние архива и последние полученные данные.

Техническая защита: HTTPS, однократные 192-битные коды с хешированием в базе, ограничение срока жизни, хешированные 256-битные сессии с защищённой HttpOnly-cookie, проверка сессии перед каждым чтением, CSRF-защита записи заметок, HTML-экранирование выводимых сообщений и запрет кеширования содержимого. Код выдаёт исключительно бот владельцу (BOT_OWNER_ID). Не открывай ссылку портала на чужих устройствах и не сохраняй профиль браузера, если не согласен передать ему доступ к содержимому своих переписок.

# Альтернативная ручная выгрузка и защищённый API

Важно: внутренняя память ChatGPT и внешняя SQLite-база Railway - разные системы. Этот проект не имеет доступа к системной памяти ChatGPT. Никакие переписки не переносятся в ChatGPT автоматически.

## Передать один чат из Telegram в ChatGPT (вручную)

1. В личном диалоге с @aialexey11_bot используй `/chats` и найди ID нужного чата.
2. Напиши `/sync_export CHAT_ID 100` (можно от 1 до 200 сообщений).
3. Бот пришлёт JSON-файл **только тебе**. Перед отправкой убедись, что согласен делиться содержимым переписки.
4. Прикрепи этот JSON к нужному разговору с ChatGPT и задай вопрос. На этом этапе это ручной перенос.

Файл содержит текст, дату, отправителя, идентификатор сообщения и признаки удаления/редактирования. Изображения и другие бинарные файлы не включаются. При повторной выгрузке выбираются актуальные последние сообщения из локального архива. Полученные данные ограничены доступностью Telegram Business API и ранее импортированных сообщений.

## Общие заметки и ручной обмен

- `/sync_note Тема | Текст`: явно сохранить заметку в SQLite.
- `/sync_notes`: показать последние заметки.
- `/sync_status`: состояние API и счётчик заметок.
- `/notes`: старый просмотр заметок оставлен без изменений.

Если нужно передать текст из ChatGPT в Telegram, сформируй здесь короткую заметку и **самостоятельно** отправь её боту командой `/sync_note`. Это не означает изменение системной памяти ChatGPT.

## Защищённый API для будущих клиентов

В приложении есть API с заголовком `Authorization: Bearer <INTEGRATION_TOKEN>`. Ключ генерируется отдельно от токена Telegram и хранится в переменных Railway, никогда в GitHub и не в сообщениях ChatGPT.

- `GET /integration/chats` - список чатов
- `GET /integration/messages/{chat_id}?limit=50` - сообщения одного чата, постранично
- `GET /integration/report/{chat_id}` - сохранённый отчёт
- `GET /integration/notes` - сохранённые заметки
- `POST /integration/notes` - добавить общую заметку JSON с полями `subject`, `content`

**Этот API сам по себе НЕ подключает данную беседу ChatGPT к архиву.** Чтобы ChatGPT мог напрямую вызывать эти методы, потребуется отдельно подключить совместимый клиент/коннектор с явной авторизацией. Ключ API не нужно присылать в чат или публиковать.

Данные в SQLite остаются на постоянном томе Railway. HTTP-эндпоинты предназначены для HTTPS; не вводи интеграционный токен в случайные сайты. Если ключ скомпрометирован, замени `INTEGRATION_TOKEN` в Railway.

## Безопасность и ограничения

- Все команды `/sync_*` доступны только владельцу (`BOT_OWNER_ID`).
- Экспорт ограничен одним явно выбранным чатом и максимум 200 сообщениями.
- Переписка не удаляется после экспорта, а записи на диске сохраняются по прежним правилам.
- Никакая автоматическая отправка или пересылка новым собеседникам не включается.
- Общие заметки - самостоятельная база, а не «Saved Memories» ChatGPT.
- Для полноценной синхронизации с памятью ChatGPT официального прямого API этого проекта нет.
